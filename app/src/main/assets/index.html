Meal Lens

One-time setup

Meal Lens uses Claude to read your photos. It needs your own Anthropic API key. Usage is billed to that key per photo, at a small cost for each one.

  1. Open console.anthropic.com, sign in, and add a little credit under Billing.
  2. Create an API key and copy it.
  3. Paste it in Settings below. It stays on this phone.
